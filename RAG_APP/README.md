# RNA Splicing RAG App

This project implements a modular, production-grade Retrieval-Augmented
Generation (RAG) system tailored for **RNA splicing research** using PDF
documents as the knowledge base.

## Features

-   Load and parse multiple PDFs from the `data/` directory\
-   Chunk documents using recursive + token-based splitting\
-   Generate embeddings using **SentenceTransformerEmbeddingFunction**\
-   Persist vector database using **ChromaDB** (no recomputation
    needed)\
-   Query augmentation using GPT\
-   Final answer generation using LLM + retrieved context\
-   CLI-based querying\
-   Modular, professional code structure with `main()` entrypoint

## Installation

Inside your backend folder:

``` bash
uv venv .venv
source .venv/bin/activate
uv pip install -r requirements.txt
```

Required libraries include:

-   pypdf
-   chromadb
-   langchain-text-splitters
-   sentence-transformers
-   python-dotenv
-   openai

------------------------------------------------------------------------

## Running the RAG Query

You can run a question from terminal:

``` bash
python backend/src/scripts/rag.py "What exons are targeted in RNA splicing therapy?"
```

This prints:

-   The **final answer**, synthesized by GPT using context\
-   The **source documents** that contributed to the answer

------------------------------------------------------------------------

## Configuration

-   PDFs must be placed in the `data/` directory\
-   Vector DB is persisted automatically in `storage/chroma/`\
-   Change model names inside `rag_app.py` as needed
